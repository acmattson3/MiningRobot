Robot Frontend Controls
=======================

Keyboard Controls
-----------------

Driving (Low mode default)
  w : drive forward
  s : drive reverse
  a : turn left
  d : turn right
  space : emergency stop

Mode Selection
  b : Low mode (drive and scoop)
  h : High mode (boom/stick/tilt or grinder)
  j : Arm mode
  P : Pop previous state

Low Mode Actions
  Arrow keys control the front scoop (fork and dump)

High Mode Actions
  Arrow keys control the arm tilt and tool/swing
  WASD control the boom and stick

Arm Mode Actions
  Arrow keys drive the four arm joints
  g : close gripper
  r : open gripper

Other Commands
  o : search for the first marker and send a MoveIt goal
  The per-marker approach offset is configured in marker_offsets.txt.
  Requires lunatic_moveit to be running.
  l / L : read left load cell while held

Power Limit Adjustments
  Hold one of the following keys and press a number (`, 0-9, -, =) to set its value:
    p : drive power
    t : tool power
    c : cut depth
    v : cut offset
    g : mining aggression
    f : autonomous driving speed

Joystick Controls
-----------------

Hold the left shoulder button to enable joystick axes.

Axes (Logitech F310 mapping)
  Left stick Y : forward/reverse
  Left stick X : turn
  Right stick X/Y : context dependent as per mode (scoop, tilt or arm joints)

Buttons
  A (1) : Low mode
  B (2) : High mode
  Y (4) : Arm mode
  X (3) : Stop
  Right shoulder (6) : grab (arm mode)
